# 相册网站 — 新电脑部署说明

单端口运行：只启动 `bin\start.bat`，访问 http://127.0.0.1:18080/#/login

## 一、拷贝文件

从开发机复制整个文件夹到新电脑（建议路径不要有中文空格问题）：

```text
相册网站-部署包/
├── bin/          start.bat、start-tunnel.bat（外网可选）
├── lib/          sq-admin-server.jar + 全部依赖 jar（缺一不可）
├── resources/    本机配置（见下文）
└── 部署说明.md   本文件
```

同时从项目 `doc/db/` 拷贝数据库脚本（首次安装需要）：

| 顺序 | 文件 |
|------|------|
| 1 | `mysql_init.sql`（系统表，库名 sqfast） |
| 2 | `album_biz_init.sql`（相册业务表，库名 photo） |
| 3 | 其余 `album_add_*.sql`（若开发机已执行过，新库也需按时间顺序执行） |

## 二、安装环境

| 软件 | 要求 |
|------|------|
| JDK | 1.8+，配置 `JAVA_HOME`；内存建议 ≥ 8GB（贴轨默认堆 2g） |
| MySQL | 8.x |
| Redis | 与配置中 host/port 一致（默认 localhost:6388） |
| ffmpeg | 视频缩略图、GPS、转码**必需**（多数家用机无 winget，见下方手动安装） |
| OSM 铁路 | 可选：`D:\uploadPath\album\osm\` 下放 `china-latest.osm.pbf` + `china-railway-index.bin.gz`；堆过小会 OOM |

验证：

```bat
java -version
D:\ffmpeg\bin\ffmpeg.exe -version
```

### ffmpeg 手动安装（无 winget 时）

1. 下载 [ffmpeg-release-essentials.zip](https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip)
2. 解压到 `D:\ffmpeg\`，确认存在 `D:\ffmpeg\bin\ffmpeg.exe` 与 `ffprobe.exe`
3. 编辑 `bin\start.bat`，取消 FFmpeg 三行 `set` 的注释（或写入 `application-local.yml` 的 `album.ffmpeg-path`）
4. 重启 `start.bat` 后，扫描页点「补封面/GPS」，应显示 `ffmpegOk=true`

## 三、初始化数据库

1. 创建库（部署机默认用 **root** 连 **photo** 库，见 `resources\application-mysql-deploy.yml`）：

```sql
CREATE DATABASE IF NOT EXISTS photo DEFAULT CHARSET utf8mb4;
```

若不用 root，请改 `application-mysql-deploy.yml` 中的 `username` / `password`。

2. 导入脚本（推荐 `doc/db/photo_sys_only_export.sql`，含表结构 + 若依 sys 数据）：

```bat
mysql -uroot -p < photo_sys_only_export.sql
```

或按文件分别导入 `album_biz_init.sql` 等到 **photo** 库。

3. 默认管理员：`admin`（密码以导入的 sys_user 为准）。

## 四、本机配置

| 文件 | 用途 |
|------|------|
| `application-mysql-deploy.yml` | 部署机 DB/Redis（root、photo、6388），打包时自动同步 |
| `application-local.yml` | 本机密钥与路径（从 example 复制，**勿提交 Git**） |

1. 复制 `resources\application-local.yml.example` 为 `resources\application-local.yml`
2. 填写高德 Key、通义 Key、本机照片路径等；**若 Redis 有密码**（报错 `NOAUTH`）须加上：

```yaml
spring:
  redis:
    password: 你的Redis密码

album:
  uploadPath: D:/uploadPath/album/upload
  thumbPath: D:/uploadPath/album/cache/thumb
  proxyPath: D:/uploadPath/album/cache/proxy
  map:
    webKey: 你的高德Web服务Key
    jsKey: 你的高德JS-API-Key
    securityJsCode: 你的安全密钥（可选，新版 Key 常需要）
```

> **3D 地形**：必须填写 `jsKey`（与控制台「Web端(JS API)」Key 对应）。只填 `webKey` 不够，开启 3D 会报「未配置高德 JS Key」。  
> 可从开发机已能用的 `application-local.yml` 复制 `map` 整段到部署机。

`start.bat` 使用 profile：**mysql-deploy,local**

3. 创建目录（或改成你本机盘符）：

```text
D:\uploadPath\album\upload
D:\uploadPath\album\cache\thumb
D:\uploadPath\album\cache\proxy
```

4. 磁盘扫描：登录后台 → 相册扫描 → 新增目录，填写**新电脑上的照片/视频路径**。

---

## 五、启动

1. 确认 MySQL、Redis 已启动
2. 双击 `bin\start.bat`
3. 浏览器打开 http://127.0.0.1:18080/#/login

停止：启动窗口 `Ctrl+C`。

---

## 六、外网访问（推荐：国内 frp，替代 Cloudflare）

熟人点链接访问请用 **阿里云 + frp**（家里相册不变，云主机只做中转）。

1. DNS：`album.pengorbit.top` A 记录指向云主机公网 IP（**灰云 / 仅 DNS**）
2. 云上按 `doc/国内frp穿透.md` 安装 frps + nginx
3. 部署机执行一次：`bin\install-frpc.bat`
4. 先 `bin\start.bat`，再 `bin\start-frp.bat`
5. 访问 https://album.pengorbit.top/#/login
6. 不要再开 `start-tunnel.bat`（cloudflared）

详见 `doc/国内frp穿透.md`。

## 七、常见问题

| 现象 | 处理 |
|------|------|
| 找不到 JAVA_HOME | 安装 JDK 并在 `start.bat` 顶部指定 `JAVA_HOME` |
| 数据库连接失败 | 检查 `application-local.yml` 的 url/账号/库名 |
| Redis 连接失败 | 改 port 或启动 Redis |
| ClassNotFoundException | `lib` 不完整，重新在本机执行 `pack-album.bat` 或整包复制 |
| 视频无法转码 | 安装 ffmpeg 并加入 PATH |
| 未配置高德 JS Key / 无法开 3D | 在 `resources\application-local.yml` 填写 `album.map.jsKey`（及可选 `securityJsCode`），重启 `start.bat` |

---

## 八、从开发机更新版本

1. 开发机运行 `pack-album.bat`
2. 只复制新电脑 `lib\` 下全部 jar（先关 start.bat）
3. 重启 `start.bat`（`resources\application-local.yml` 保留不动）
