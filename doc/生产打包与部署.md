
# 生产部署与打包指南

## 0. 构建环境要求

### 0.1 工具版本

| 工具 | 版本要求 | 说明 |
|---|---|---|
| Maven | >= 3.5.4 | flatten-maven-plugin 要求 |
| JDK | >= 1.8 | |

### 0.2 环境变量速查表

以下为生产环境需要配置的环境变量：

| 环境变量 | 是否必须 | 说明 | 默认值 |
|---|---|---|---|
| `SQ_JWT_SECRET` | 是 | JWT 签名密钥（256 位） | `sq-dev-jwt-secret-please-override-in-prod` |
| `SQ_KEYSTORE_PATH` | 否 | 外部 keystore 文件路径（推荐配置） | 空（使用 classpath） |
| `SQ_KEYSTORE_PWD` | 是 | keystore 存储密码 | `sq-dev-store-pwd` |
| `SQ_KEY_PWD` | 是 | 私钥密码 | `sq-dev-key-pwd` |
| `DB_USERNAME` | 推荐 | 数据库用户名 | 配置文件中明文 |
| `DB_PASSWORD` | 推荐 | 数据库密码（未设置时 fallback JASYPT_DB_PASSWORD） | 配置文件中明文 |
| `REDIS_PASSWORD` | 否 | Redis 密码（未设置时 fallback JASYPT_REDIS_PASSWORD） | 空 |
| `SQ_UPLOAD_PATH` | 否 | 文件上传存储路径 | `/home/sq/upload` |
| `JASYPT_ENCRYPTOR_PASSWORD` | 是 | jasypt 加密密钥（解密 ENC() 值） | 无默认值，必须注入 |
| `JASYPT_DB_PASSWORD` | 推荐 | 数据库密码加密值（格式 `ENC(密文)`） | 无 |
| `JASYPT_REDIS_PASSWORD` | 否 | Redis 密码加密值（格式 `ENC(密文)`） | 无 |

> 建议通过环境变量或配置中心注入敏感信息，不要在配置文件或命令行中明文存储。

## 1. 证书制作（Keystore）

项目使用 SM2（国密）证书，keystore 格式为 PKCS12（`.p12` / `.pfx`）。开发环境使用 classpath 中的 `keystore/sq-sm2.p12`，生产环境建议使用自制证书。

### 1.1 使用 keytool 生成自签名证书（SM2）

```bash
# 生成 SM2 密钥对并存入 PKCS12 keystore
keytool -genkeypair -alias sq-sm2 -keyalg EC -keysize 256 \
  -sigalg SM3withSM2 -storetype PKCS12 \
  -keystore sq-sm2.p12 \
  -storepass your-store-pwd \
  -keypass your-key-pwd \
  -dname "CN=你的系统域名或IP, OU=你的部门, O=你的公司, L=你的城市, ST=省份, C=CN" \
  -validity 3650
```

参数说明：

| 参数 | 含义 |
|---|---|
| `-alias sq-sm2` | 密钥别名，需与 `application.yml` 中 `sq.crypto.sm2.alias` 一致 |
| `-keyalg EC` | 椭圆曲线算法（SM2 基于 EC） |
| `-keysize 256` | 密钥长度 256 位 |
| `-sigalg SM3withSM2` | SM2 签名算法 |
| `-storetype PKCS12` | 存储格式 |
| `-validity 3650` | 有效期（天），约 10 年 |

> 如 JDK 不支持 SM3withSM2（JDK 8 以下），可使用 Bouncy Castle 或 OpenSSL 1.1.1+ 生成。

### 1.2 使用 OpenSSL 生成（备选）

```bash
# 1. 生成 SM2 私钥
openssl ecparam -genkey -name SM2 -out sm2-private.pem

# 2. 生成自签名证书
openssl req -new -x509 -key sm2-private.pem -out sm2-cert.pem \
  -days 3650 -subj "/C=CN/ST=省份/L=城市/O=公司/OU=部门/CN=域名或IP"

# 3. 打包为 PKCS12
openssl pkcs12 -export -in sm2-cert.pem -inkey sm2-private.pem \
  -out sq-sm2.p12 -name sq-sm2 \
  -passout pass:your-store-pwd
```

### 1.3 部署证书

```bash
# 方式一：外部路径（推荐）
# 将 sq-sm2.p12 放置在服务器安全目录，如 /etc/keystore/sq-sm2.p12
# 启动时通过环境变量指定：
export SQ_KEYSTORE_PATH=/etc/keystore/sq-sm2.p12
export SQ_KEYSTORE_PWD=your-store-pwd
export SQ_KEY_PWD=your-key-pwd

# 方式二：替换 classpath 中的默认证书
# 直接将 sq-sm2.p12 覆盖到 sq-admin-server/src/main/resources/keystore/
# 然后重新打包
```

### 1.4 查看证书信息

```bash
keytool -list -v -keystore sq-sm2.p12 -storetype PKCS12 -storepass your-store-pwd
```

## 2. 生产环境配置

### 2.1 JWT 密钥与 Token 过期时间

`application.yml`：

```yaml
token:
  secret: ${SQ_JWT_SECRET:dev-only-fallback}   # 生产必须通过环境变量注入
  expireTime: 180                               # Token 有效期（分钟）
```

部署时通过环境变量注入：

```bash
# Linux / macOS
export SQ_JWT_SECRET=your-256-bit-secret

# Windows PowerShell
$env:SQ_JWT_SECRET="your-256-bit-secret"
```

### 2.2 密码安全策略

```yaml
user:
  password:
    maxRetryCount: 5      # 密码最大错误次数（建议生产环境适当调低）
    lockTime: 10          # 锁定时间（分钟）
```

可通过环境变量覆盖：

| 变量 | 示例 |
|---|---|
| `USER_PASSWORD_MAXRETRYCOUNT` | `USER_PASSWORD_MAXRETRYCOUNT=3` |
| `USER_PASSWORD_LOCKTIME` | `USER_PASSWORD_LOCKTIME=30` |

### 2.3 数据库连接

```yaml
spring:
  datasource:
    url: jdbc:mysql://prod-host:3306/dbname?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
```

### 2.4 application-mysql-prod.yml 配置说明

`application-mysql-prod.yml` 中的配置项按用途分为三类：

| 类别 | 包含项 | 说明 |
|---|---|---|
| ✅ **已配默认值，不要修改** | Druid 连接池参数（initialSize/minIdle/maxActive/maxWait/timeBetweenEvictionRunsMillis/minEvictableIdleTimeMillis/maxEvictableIdleTimeMillis/validationQuery）、Druid 监控关闭（webStatFilter/statViewServlet）、Wall 配置（multi-statement-allow）、Devtools 热部署关闭、Redis 连接池参数（lettuce.pool）、日志级别（logging.level）、Knife4j 关闭、jasypt 配置结构 | 这些是生产环境安全/性能基线值，所有数据库 profile 共用，不应修改 |
| 📋 **参照结构，其他 profile 复制** | 数据源配置骨架（`spring.datasource.type/driverClassName/druid.master`）+ 连接池 + 过滤器的 YAML 结构 | 达梦/GaussDB 的 prod 配置应复制此结构，仅替换 `driverClassName` 和 `url` |
| 🔧 **需单独配置** | `spring.datasource.druid.master.url`（数据库地址/库名）、`username`、`password`（通过环境变量）、Redis 的 `host/port/database` | 每个部署环境不同，按实际修改 |

### 2.5 数据库选择

| 数据库 | Maven Profile | 启动命令 |
|---|---|---|
| MySQL | `mysql-prod` | `java -jar app.jar --spring.profiles.active=mysql-prod` |
| 达梦 DM8 | `dm-prod` | `java -jar app.jar --spring.profiles.active=dm-prod` |
| GaussDB | `gaussdb-prod` | `java -jar app.jar --spring.profiles.active=gaussdb-prod` |

### 2.5 生产环境 Source Map 安全

Source Map 在生产环境应关闭，防止源码泄露：

**Vue2**（`sq-ui/vue.config.js`，已配置）：

```js
productionSourceMap: false
```

**Vue3**（`sq-ui-vue3/vite.config.js`，建议显式声明）：

```js
build: {
  sourcemap: false
}
```

如已接入错误监控平台（Sentry / ARMS），可将值改为 `'hidden'`，仅生成 .map 文件但不部署到 CDN。

## 3. 构建

### 3.1 构建后端

```bash
# 在项目根目录执行（包含 sq-system、sq-business、sq-admin-server）
mvn clean package -DskipTests -P mysql-prod

# 针对特定数据库的 Profile：
# -P mysql-prod    MySQL 生产环境
# -P dm-prod       达梦 DM8 生产环境
# -P gaussdb-prod  GaussDB 生产环境
```

构建产物：`sq-admin-server/target/sq-admin-server.jar`

### 3.2 构建前端

```bash
# Vue2
cd sq-ui
npm install --registry=https://registry.npmmirror.com
npm run build:prod     # 产出 dist/

# Vue3
cd sq-ui-vue3
npm install --registry=https://registry.npmmirror.com
npm run build:prod     # 产出 dist/
```

## 4. 前后端合并部署（推荐）

将前端产物合并到后端 jar 中，实现单包部署：

```bash
# 1. 将 dist/ 下所有文件（不含 dist 目录本身）复制到后端静态资源目录
cp -r sq-ui/dist/*   sq-admin-server/src/main/resources/static/
# 或 Vue3
cp -r sq-ui-vue3/dist/*  sq-admin-server/src/main/resources/static/

# 2. SecurityConfig 中添加放行
#    .antMatchers("/", "/index.html", "/static/**", "/api/**").permitAll()

# 3. 去除 SysIndexController 中访问项目根路径的首页提示语
#    使根路径直接跳转 index.html

# 4. 重新打包后端
mvn clean package -DskipTests -P mysql-prod

# 5. 部署 sq-admin-server.jar
java -jar sq-admin-server/target/sq-admin-server.jar --spring.profiles.active=mysql-prod
```

详见 [前后端合并部署流程](./前后端合并部署流程.md)。

## 5. 环境变量注入方式

### 5.1 Linux / macOS（推荐方式）

编辑 `/etc/profile` 或应用启动脚本 `start.sh`：

```bash
export SQ_JWT_SECRET="your-256-bit-secret"
export SQ_KEYSTORE_PWD="your-store-pwd"
export SQ_KEY_PWD="your-key-pwd"
export DB_USERNAME="prod_user"
export DB_PASSWORD="prod_password"
export JASYPT_ENCRYPTOR_PASSWORD="your-jasypt-master-key"

java -jar sq-admin-server.jar --spring.profiles.active=mysql-prod
```

### 5.2 Windows PowerShell

`start.ps1`：

```powershell
$env:SQ_JWT_SECRET="your-256-bit-secret"
$env:SQ_KEYSTORE_PWD="your-store-pwd"
$env:SQ_KEY_PWD="your-key-pwd"
$env:DB_USERNAME="prod_user"
$env:DB_PASSWORD="prod_password"
$env:JASYPT_ENCRYPTOR_PASSWORD="your-jasypt-master-key"

java -jar sq-admin-server.jar --spring.profiles.active=mysql-prod
```

### 5.3 通过命令行参数注入

```bash
java -jar sq-admin-server.jar \
  --spring.profiles.active=mysql-prod \
  --spring.datasource.username=prod_user \
  --spring.datasource.password=prod_pass \
  --SQ_JWT_SECRET=your-secret-key \
  --SQ_KEYSTORE_PWD=your-store-pwd \
  --SQ_KEY_PWD=your-key-pwd \
  --JASYPT_ENCRYPTOR_PASSWORD=your-jasypt-master-key \
  --server.port=8080
```

### 5.4 Docker 环境变量

```bash
docker run -d -p 8080:8080 \
  -e SQ_JWT_SECRET=your-256-bit-secret \
  -e SQ_KEYSTORE_PWD=your-store-pwd \
  -e SQ_KEY_PWD=your-key-pwd \
  -e DB_USERNAME=prod_user \
  -e DB_PASSWORD=prod_password \
  -e JASYPT_ENCRYPTOR_PASSWORD=your-jasypt-master-key \
  -v /etc/keystore:/etc/keystore \
  your-image:tag
```
