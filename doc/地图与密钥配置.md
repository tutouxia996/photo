# 地图与第三方密钥配置

相册项目用到的地图 / AI Key **分前后端两处**，不要混放。

| 服务 | 用途 | 配置位置 | 环境变量（可选） |
|------|------|----------|------------------|
| 高德 Web | 地点检索、路径规划、地理编码等（后端） | `application-local.yml` → `album.map.webKey` | `AMAP_WEB_KEY` |
| 高德 JS | 预留，当前前端未用官方 JS SDK | `album.map.jsKey` | `AMAP_JS_KEY` |
| 通义 DashScope | AI 地标识别、万相出图（后端） | `album.aiLandmark.apiKey` / `album.photoDraw.apiKey` | `AI_LANDMARK_API_KEY` 等 |
| 百度浏览器端 AK | 前端「百度地图」引擎（标准/卫星/全景） | Vue3 `.env*.local` → `VITE_BAIDU_MAP_AK` | 同左（构建时注入） |

---

## 一、后端：高德、通义

1. 复制示例为本地文件（**勿提交 Git**）：

```text
sq-admin-server/src/main/resources/application-local.yml.example
  → application-local.yml
```

部署包内对应：

```text
resources/application-local.yml.example → application-local.yml
```

2. 填写示例中的 `webKey`、`apiKey` 等，重启后端（profile 需包含 `local`）。

说明见各 example 文件顶部注释。

---

## 二、前端：高德 / 百度双引擎

地图右上角为 **高德地图 | 百度地图** 并列切换：

| 引擎 | 样式下拉 | 实现 |
|------|----------|------|
| 高德地图 | 标准 / 卫星 / 混合 | Leaflet + 高德公开瓦片（GCJ-02） |
| 百度地图 | 标准 / 卫星 / 全景 | 百度 JS API `BMap`（BD-09） |

上次选择的引擎与样式会写入浏览器 `localStorage`（`album.map.providerPrefs`）。

照片/视频点、轨迹、GPX、规划折线、行政区高亮，以及路段编辑、拖点纠正、框选等交互在两端均适配；**路径规划请求仍走后端高德 Web Key**，仅展示时按当前底图坐标系转换。

### 1. 申请百度 AK 与开通

1. [百度地图开放平台](https://lbsyun.baidu.com/) 完成开发者认证  
2. 控制台创建应用：**浏览器端** AK  
3. Referer 白名单示例：

```text
localhost,127.0.0.1,album.pengorbit.top
```

不要写带 `#/login` 的完整 URL。  
4. 开通 **JavaScript API**；**全景**为高级权限，常需单独申请试用。  
   百度「全景」样式依赖 `PanoramaCoverageLayer` + `PanoramaControl`。

### 2. 写入项目

真实 AK 放在 **gitignore 的 `.local` 文件**：

```text
sq-ui-vue3/.env.development.local
sq-ui-vue3/.env.production.local
```

```env
VITE_BAIDU_MAP_AK=你的浏览器端AK
```

代码：

- 坐标与加载：`sq-ui-vue3/src/utils/baiduMap.js`
- 引擎：`sq-ui-vue3/src/utils/mapAdapters/baiduEngine.js`
- 高德 Leaflet 瓦片：`sq-ui-vue3/src/utils/mapAdapters/amapLeaflet.js`
- 入口：`PhotoClusterMap` 右上角切换

未配置 AK 时点击「百度地图」会提示并留在高德。

### 3. 生效方式

| 场景 | 操作 |
|------|------|
| 本地开发 | 改 `.env.development.local` 后 **重启** `npm run dev` |
| 合并部署 / 线上 | 打包前存在 `.env.production.local`（或 CI 注入 `VITE_BAIDU_MAP_AK`），再 `npm run build:prod` |
