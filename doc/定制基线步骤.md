
# 基于基线的定制步骤

基于 sq-fast 基线版本研发新系统的关键配置项，按需调整即可快速落地。

---

## 前端定制

### 1. 调整系统名称

前端系统名称统一由 `.env` 环境变量驱动：

| 前端 | 文件 | 修改为 |
|---|---|---|
| Vue2 | `sq-ui/.env.development` | `VUE_APP_TITLE = 你的系统名称` |
| Vue2 | `sq-ui/.env.production` | `VUE_APP_TITLE = 你的系统名称` |
| Vue2 | `sq-ui/.env.staging` | `VUE_APP_TITLE = 你的系统名称` |
| Vue3 | `sq-ui-vue3/.env.development` | `VITE_APP_TITLE = 你的系统名称` |
| Vue3 | `sq-ui-vue3/.env.production` | `VITE_APP_TITLE = 你的系统名称` |
| Vue3 | `sq-ui-vue3/.env.staging` | `VITE_APP_TITLE = 你的系统名称` |

影响范围：浏览器标签栏标题、侧边栏左上角 Logo 标题、登录页品牌名称。

代码兜底：如果 .env 未配置，默认显示"相册管理平台"。

---

### 2. 调整默认主题

#### 默认侧边栏主题

`sq-ui/src/settings.js`（Vue2）或 `sq-ui-vue3/src/settings.js`（Vue3）：

```js
// 深色主题 theme-dark，浅色主题 theme-light
sideTheme: 'theme-dark',
```

#### 默认主题色（强调色 Hex）

Vue2 `sq-ui/src/store/modules/settings.js:8`：

```js
theme: storageSetting.theme || '#409EFF',  // 改为你的品牌色
```

Vue3 `sq-ui-vue3/src/store/modules/settings.js:17`：

```js
theme: storageSetting.theme || '#409EFF',
```

用户在前端「布局设置」面板手动保存主题色后，会写入 `localStorage['layout-setting']` 并优先使用。如需重置，清除浏览器 `localStorage` 即可。

### 4. 调整侧边栏 Logo 样式

#### Vue2

`sq-ui/src/layout/components/Sidebar/Logo.vue`：

- `height: 50px` — 侧边栏顶部高度
- `font-size: 16px` — 标题字号
- HUD 角标、扫光、二进制字符、数据流虚线等装饰元素均在 `<style>` 中

#### Vue3

`sq-ui-vue3/src/layout/components/Sidebar/Logo.vue`：

- 同上，CSS 样式一致
- 文字通过 `v-bind(getLogoTextColor)` 与 `background-clip: text` 实现蓝色渐变

## 后端定制

### 1. 调整 Swagger 标题

`sq-admin-server/src/main/resources/application-{profile}.yml`：

```yaml
swagger:
  title: 你的系统接口文档
```

---

### 2. 调整密码策略

`sq-admin-server/src/main/resources/application.yml`：

```yaml
user:
  password:
    maxRetryCount: 5      # 最大重试次数
    lockTime: 10          # 锁定时间（分钟）
```

可通过环境变量覆盖：

| 变量 | 示例 |
|---|---|
| `USER_PASSWORD_MAXRETRYCOUNT` | `USER_PASSWORD_MAXRETRYCOUNT=3` |
| `USER_PASSWORD_LOCKTIME` | `USER_PASSWORD_LOCKTIME=30` |

---

### 3. 调整 JWT 密钥与过期时间

`sq-admin-server/src/main/resources/application.yml`：

```yaml
token:
  secret: ${SQ_JWT_SECRET:dev-only-fallback}   # 生产必须设置 SQ_JWT_SECRET
  expireTime: 180                               # Token 有效期（分钟）
```

生产部署时通过环境变量注入：

```bash
export SQ_JWT_SECRET=your-256-bit-secret
export SQ_KEYSTORE_PWD=your-keystore-password
export SQ_KEY_PWD=your-key-password
```

---

### 4. 数据库选择

| 数据库 | Maven Profile | application 配置 |
|---|---|---|
| MySQL | `mysql-dev` / `mysql-prod` | `application-mysql-dev.yml` |
| 达梦 DM8 | `dm-dev` | `application-dm-dev.yml` |
| GaussDB | `gaussdb-dev` | `application-gaussdb-dev.yml` |

启动命令：

```bash
# MySQL 开发环境
mvn spring-boot:run -Dspring-boot.run.profiles=mysql-dev

# 达梦
mvn spring-boot:run -Dspring-boot.run.profiles=dm-dev

# GaussDB
mvn spring-boot:run -Dspring-boot.run.profiles=gaussdb-dev
```
