# 相册网站家用合并部署说明

前后端已合并为**单端口**运行：只启动后端即可，前端静态资源已打进包内。

适用于桌面部署包：`相册网站-部署包`。更细操作以桌面包内 `部署说明.md` 为准。

## 目录结构

```text
相册网站-部署包/
├── bin/start.bat       Windows 启动脚本
├── lib/                sq-admin-server.jar + 依赖 jar
├── resources/          配置参考副本
└── 部署说明.md
```

## 环境要求

- JDK ≥ 1.8（`JAVA_HOME` 已配置）
- MySQL 8（已执行库初始化脚本）
- Redis（按所用 profile 中的 host/port）
- 外网：`D:\cloudflared\cloudflared.exe`（Cloudflare Tunnel）

## 启动相册

1. 编辑 `bin/start.bat`：按需修改 profile、端口、上传目录  
2. 双击 `bin/start.bat`  
3. 本机打开：http://127.0.0.1:18080/#/login  

停止：启动窗口 `Ctrl+C`。

## 外网访问（推荐：固定域名，免费）

当前已配置好的生产用法：

| 项 | 值 |
|----|-----|
| 域名 | `pengorbit.top`（阿里云购买，DNS 已接到 Cloudflare） |
| 外网地址 | **https://album.pengorbit.top/#/login** |
| 隧道名 | `album-home` |
| 本机源站 | `http://127.0.0.1:18080` |
| 配置文件 | `%USERPROFILE%\.cloudflared\config.yml` |
| 凭证 | `%USERPROFILE%\.cloudflared\*.json` 与 `cert.pem`（勿外传） |

### 日常启动（两件事都要开）

```text
1. 启动相册（18080）
2. 启动隧道：
   D:\cloudflared\cloudflared.exe tunnel run album-home
```

也可用（会读默认 config）：

```bat
cd /d D:\cloudflared
cloudflared.exe tunnel run album-home
```

隧道窗口不要关；电脑休眠/关机则外网不可用。

### 说明

- 此 Named Tunnel 通过 **`cloudflared tunnel login` + CLI** 创建，**不依赖** Zero Trust 控制台绑卡。  
- 控制台里 Zero Trust「要信用卡」的页面可以忽略；固定域名已可用。  
- 首次搭建设骤见：`doc/Cloudflare固定域名隧道.md`。

### 备用：临时隧道（地址会变）

未开 Named Tunnel、或排查问题时可用：

```bat
cloudflared.exe tunnel --url http://127.0.0.1:18080
```

使用日志中的 `https://xxxx.trycloudflare.com/#/login`（每次重启会变）。

## 怎样打成单端口包

### 原理

把 Vue3 生产构建产物放进后端 `src/main/resources/static/`，再 `mvn package`。运行时只开 **18080**。

### 一次性改动（仓库已完成）

| 项 | 说明 |
|----|------|
| 路由 | `createWebHashHistory()` |
| `.env.production` | `VITE_APP_BASE_API = ''` |
| 百度街景（可选） | 打包前在 `.env.production.local` 设置 `VITE_BAIDU_MAP_AK`（gitignore）；详见 `doc/地图与密钥配置.md` |
| 首页控制器 | `/` → `forward:/index.html` |
| Security | 放行静态资源与首页 |

### 每次出包

```powershell
$root = "D:\work\学习\相册网站"
cd "$root\sq-ui-vue3"; npm run build:prod

$static = "$root\sq-admin-server\src\main\resources\static"
Remove-Item $static -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force -Path $static | Out-Null
Copy-Item -Recurse -Force "$root\sq-ui-vue3\dist\*" $static

cd $root; mvn clean package -DskipTests

$deskLib = Join-Path ([Environment]::GetFolderPath("Desktop")) "相册网站-部署包\lib"
Copy-Item -Force "$root\sq-admin-server\target\sq-admin-server.jar" $deskLib
Copy-Item -Force "$root\sq-admin-server\target\lib\*" $deskLib
```

校验：

```powershell
jar tf "...\sq-admin-server.jar" | findstr "BOOT-INF/classes/static/index.html"
```

| 场景 | 方式 |
|------|------|
| 日常改页面 | `npm run dev`（5173）+ 后端 18080 |
| 外网/单进程 | 单端口包 + 只开 18080 |

详见：`doc/生产打包与部署.md`、`doc/Cloudflare固定域名隧道.md`。
