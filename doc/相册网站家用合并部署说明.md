# 相册网站家用合并部署说明

前后端已合并为**单端口**运行：只启动后端即可，前端静态资源已打进包内。

适用于桌面部署包：`相册网站-部署包`（`sq-admin-server` 瘦 jar + `lib` 依赖）。更细的操作以桌面包内 `部署说明.md` 为准。

## 目录结构

```text
相册网站-部署包/
├── bin/start.bat       Windows 启动脚本
├── lib/                sq-admin-server.jar + 依赖 jar
├── resources/          配置参考副本
└── 部署说明.md
```

## 环境要求

- JDK ≥ 1.8（`JAVA_HOME` 已配置）
- MySQL 8（已执行 `doc/db/mysql_init.sql`）
- Redis（按所用 profile 中的 host/port）
- 外网访问可选：`D:\cloudflared\cloudflared.exe`

## 启动相册

1. 编辑 `bin/start.bat`：按需修改 `SPRING_PROFILES`、`SERVER_PORT`、`SQ_UPLOAD_PATH`
2. 双击 `bin/start.bat`
3. 本机打开：http://127.0.0.1:18080/#/login

停止：启动窗口 `Ctrl+C`。

## Cloudflare 临时隧道（无公网 IP）

**必须先本机能打开登录页，再开隧道。**

```bat
cd /d D:\cloudflared
cloudflared.exe tunnel --url http://127.0.0.1:18080
```

注意：

| 要点 | 说明 |
|------|------|
| 必须带 `--url` | 只写 `tunnel` 通常不会生成可访问链接 |
| 找 `trycloudflare.com` | 地址多在日志靠前；看不到就往上翻，或重启隧道后立刻复制 |
| `config.yml` 提示 | `Cannot determine default configuration path` 可忽略 |
| 日志确认 | 应出现 `url:http://127.0.0.1:18080`，且预检查为 `PASS` |
| 登录地址 | `https://xxxx.trycloudflare.com/#/login` |
| 窗口不要关 | 关掉 cloudflared / 休眠电脑 = 外网断开；域名每次会变 |

## 推荐顺序

```text
MySQL/Redis → start.bat → 本机确认登录页 → cloudflared --url 18080 → 复制链接
```

## 怎样打成单端口包

### 原理

把 Vue3 生产构建产物放进后端 `src/main/resources/static/`，再 `mvn package`。运行时只开 **18080**：页面和 API 同域。

```text
浏览器 → :18080
          ├── /#/...     前端（static）
          └── /album/... 后端 API
```

### 一次性改动（仓库已完成）

| 项 | 说明 |
|----|------|
| 路由 | `createWebHashHistory()`，避免无 Nginx 时刷新 404 |
| `.env.production` | `VITE_APP_BASE_API = ''`，同域调接口 |
| `SysIndexController` | `/` → `forward:/index.html` |
| `SecurityConfig` | 放行静态资源与首页 |
| `.gitignore` | 忽略 `static/` 构建产物 |

### 每次出包步骤

项目根：`D:\work\学习\相册网站`

```powershell
# 1) 前端生产构建
cd "D:\work\学习\相册网站\sq-ui-vue3"
npm run build:prod

# 2) 拷贝到后端 static
$static = "D:\work\学习\相册网站\sq-admin-server\src\main\resources\static"
Remove-Item $static -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force -Path $static | Out-Null
Copy-Item -Recurse -Force "D:\work\学习\相册网站\sq-ui-vue3\dist\*" $static

# 3) 打后端包（瘦 jar + target/lib）
cd "D:\work\学习\相册网站"
mvn clean package -DskipTests

# 4) 覆盖桌面部署包
$deskLib = Join-Path ([Environment]::GetFolderPath("Desktop")) "相册网站-部署包\lib"
Copy-Item -Force "D:\work\学习\相册网站\sq-admin-server\target\sq-admin-server.jar" $deskLib
Copy-Item -Force "D:\work\学习\相册网站\sq-admin-server\target\lib\*" $deskLib
```

校验 jar 内是否含前端：

```powershell
jar tf "...\sq-admin-server\target\sq-admin-server.jar" | findstr "BOOT-INF/classes/static/index.html"
```

### 开发 vs 单端口

| 场景 | 方式 |
|------|------|
| 日常改页面 | `npm run dev`（5173）+ 后端 18080 |
| 外网/单进程 | 按上面打单端口包，只开 18080 |

生产环境变量等详见：`doc/生产打包与部署.md`。桌面包内完整版见：`部署说明.md` 第 7 节。
