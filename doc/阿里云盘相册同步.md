# 阿里云盘个人相册定时同步

将阿里云盘「个人相册」中的**一个相册**增量下载到本机目录，再复用现有磁盘扫描入库到项目相册。

## 流程

```text
阿里云盘个人相册（一个）
  → 定时任务 aliyunAlbumSyncTask.syncAndScan()
  → 下载到 F:\照片视频备份\平时拍照
  → IBizScanPathService.startScanAsync（增量）
  → biz_photo / 项目相册
```

## 一次性配置

### 1. 获取 refresh_token

1. 浏览器登录 [阿里云盘](https://www.alipan.com)
2. F12 → Application → Local Storage → 选中站点
3. 找到 `token`（或含 `refresh_token` 的项），复制其中的 `refresh_token` 值

> 每次刷新后旧 token 会失效；程序会把最新 token 写到 `tokenFile`，请保证该文件可写。

### 2. 本地配置

复制 `sq-admin-server/src/main/resources/application-local.yml.example` 为 `application-local.yml`，填写：

```yaml
album:
  aliyunDrive:
    enabled: true
    refreshToken: 你的refresh_token
    remoteAlbumName: 平时拍照   # 或改填 remoteAlbumId
    localPath: F:/照片视频备份/平时拍照
    scanPathId: 1               # 见下一步
    triggerScan: true
    fullScan: false
    tokenFile: D:/uploadPath/album/aliyun-drive-token.json
```

启动需激活 `local` profile（例如 `-Dspring.profiles.active=mysql-dev,local`）。

### 3. 绑定磁盘扫描目录

后台 → **相册管理 → 磁盘扫描**：

1. 新增扫描目录：`localPath` = `F:\照片视频备份\平时拍照`（与配置一致）
2. **默认绑定相册**选项目里的目标相册
3. 记下该行的 `pathId`，填回 `album.aliyunDrive.scanPathId`

未填 `scanPathId` 时，会按 `localPath` 自动匹配已启用的扫描目录。

### 4. 配置定时任务

后台 → **系统监控 → 定时任务** → 新增：

| 项 | 值 |
|----|-----|
| 任务名称 | 阿里云盘相册同步 |
| 调用目标 | `aliyunAlbumSyncTask.syncAndScan()` |
| cron | 例如每天 2 点：`0 0 2 * * ?` |
| 并发执行 | 禁止 |
| 状态 | 正常 |

也可在列表里点「执行一次」做联调。

## 行为说明

- `mediaOnly=false` 时下载相册内全部原文件（格式不限）；`true` 时仅常见图片/视频扩展名
- 本地已存在且大小一致则跳过（增量）
- 大文件（默认 ≥2MB）使用 HTTP Range 多分片并行下载（`chunkConcurrency`，默认 8），接近官方多连接加速；不支持 Range 时自动回退单连接
- 文件级并发 `downloadConcurrency` 建议 2～3，总连接约 ≈ 文件数 × 分片数
- 同名冲突时文件名追加 `fileId` 前缀片段
- 不会从本机删除云盘已删文件（第一期不做双向删除）
- `enabled=false` 时任务直接跳过并写日志

## 排查

1. 看后端日志关键字：`阿里云盘` / `aliyunAlbumSyncTask`
2. 确认 `tokenFile` 已生成且 `refreshToken` 在更新
3. 确认本机目录有新文件后，磁盘扫描日志是否有新增入库
