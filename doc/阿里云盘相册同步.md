# 阿里云盘个人相册定时同步

将阿里云盘「个人相册」中的相册增量下载到本机目录，再复用现有磁盘扫描入库到项目相册。

## 流程

```text
阿里云盘个人相册
  → 定时任务 aliyunAlbumSyncTask.syncAndScan()
    → 读取后台「云盘同步」配置（未保存则回落 yml）
  → 下载到本机目录
  → IBizScanPathService.startScanAsync（增量）
  → biz_photo / 项目相册
```

## 一次性配置

### 1. 建表与菜单

已有库执行：

```text
doc/db/album_add_aliyun_drive_setting.sql
```

执行后重新登录后台，菜单出现：**相册管理 → 云盘同步**。

若曾配置过 token 文件，部署库可清空：

```sql
UPDATE biz_aliyun_drive_setting
SET token_file = '',
    update_time = NOW()
WHERE id = 1;
```

### 2. 获取 refresh_token

1. 浏览器登录 [阿里云盘](https://www.alipan.com)
2. F12 → Application → Local Storage → 选中站点
3. 找到 `token`（或含 `refresh_token` 的项），复制其中的 `refresh_token` 值

> 每次刷新后旧 token 会失效；程序把最新 token **只写数据库** `biz_aliyun_drive_setting.refresh_token`。

### 3. 页面保存（推荐）

后台 → **相册管理 → 云盘同步**：

1. 打开「启用同步」，粘贴 `refresh_token`
2. 选好云盘相册、本机父目录等
3. 点 **保存**（服务端会校验 token，轮换后写入数据库；无效会直接报错）
4. 再点 **开始同步**

页面保存后配置在表 `biz_aliyun_drive_setting`（id=1），覆盖 yml。`refresh_token` 只回显脱敏值，留空保存表示不改动。

### 4. 绑定磁盘扫描目录

后台 → **相册管理 → 磁盘扫描**：

1. 新增扫描目录：本地路径与云盘同步的「本机下载目录」一致
2. **默认绑定相册**选项目里的目标相册
3. 在云盘同步页选择该扫描目录

未选扫描目录时，会按本机路径自动匹配已启用的扫描目录。

### 5. 配置定时任务

后台 → **系统监控 → 定时任务** → 新增：

| 项 | 值 |
|----|-----|
| 任务名称 | 阿里云盘相册同步 |
| 调用目标 | `aliyunAlbumSyncTask.syncAndScan()` |
| cron | 例如每天凌晨 1 点：`0 0 1 * * ?` |
| 并发执行 | 禁止 |
| 状态 | 正常 |

也可在云盘同步页点「开始同步」，或在定时任务列表「执行一次」。已暂停的任务定时器会跳过，需在页面点「继续」。

yml（`application-local.yml`）仅在**尚未在页面保存过**时作为默认值；保存后以页面为准。

## 行为说明

- `仅图片/视频` 关闭时下载相册内全部原文件（格式不限）
- 本地已存在且大小一致则跳过（增量）
- 大文件（默认 ≥2MB）使用 HTTP Range 多分片并行下载
- 文件级并发建议 2～3，总连接约 ≈ 文件数 × 分片数
- 同名冲突时文件名追加 `fileId` 前缀片段
- 不会从本机删除云盘已删文件（第一期不做双向删除）
- 未启用时任务直接跳过并写日志
- 下载不阻塞其它页面；右下角浮层显示进度与剩余个数，支持暂停 / 继续
- 进度保存在进程内存；重启后需重新点同步（增量仍会按本地已有文件跳过）
- 暂停后不会触发磁盘扫描；全部下完才扫描入库
- 个别相册条目（常见于手机备份视频）在备份盘/资源库均 404 时记为缺失并跳过，继续下载会重试其它盘；已确认不存在的不会反复报失败

## 排查

1. 看后端日志关键字：`阿里云盘` / `aliyunAlbumSyncTask`
2. 确认库表 `biz_aliyun_drive_setting.refresh_token` 在保存/同步后有更新
3. 确认本机目录有新文件后，磁盘扫描日志是否有新增入库
